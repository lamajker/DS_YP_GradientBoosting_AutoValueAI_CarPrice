# DS_YP_GradientBoosting_AutoValueAI_CarPrice

## Описание проекта

В рамках проекта была разработана модель машинного обучения для сервиса AutoValue AI, занимающегося мгновенным выкупом автомобилей на вторичном рынке.

Цель проекта - построить систему автоматической оценки стоимости автомобиля на основе исторических данных о сделках и выбрать наиболее эффективную библиотеку градиентного бустинга среди:

- CatBoost
- LightGBM
- XGBoost

Особое внимание уделялось не только качеству прогнозирования, но и бизнес-рискам, связанным с ошибками оценки стоимости автомобилей.

---

## Цель исследования

Построить модель, способную автоматически определять рыночную стоимость автомобиля на основе его характеристик и обеспечить:

- минимальную среднюю ошибку прогнозирования;
- низкий риск опасной переплаты при выкупе автомобиля;
- минимальные потери потенциальной прибыли из-за занижения цены;
- стабильную работу на новых данных.

---

## Бизнес-метрики проекта

Помимо стандартных метрик регрессии использовались специальные бизнес-метрики.

### Overpricing Rate

Доля случаев, когда модель завысила стоимость автомобиля более чем на 20%.

Такие ошибки могут привести к прямым финансовым потерям компании при выкупе автомобилей.

### Underpricing Loss

Суммарная недополученная прибыль в случаях, когда модель занизила стоимость автомобиля более чем на 20%.

Такие ошибки могут приводить к потере клиентов.

## Этапы работы

### 1. Исследовательский анализ данных (EDA)

Выполнено:

- изучение структуры данных;
- анализ типов признаков;
- проверка пропусков и дубликатов;
- исследование распределения целевой переменной;
- анализ взаимосвязей между признаками с использованием коэффициента PhiK;
- первичный бизнес-анализ стоимости автомобилей по брендам и регионам.

---

### 2. Подготовка данных

Выполнено:

- разделение признаков на числовые и категориальные;
- формирование обучающей и валидационной выборок;
- подготовка данных для различных библиотек градиентного бустинга;
- перевод категориальных признаков в тип `category` для CatBoost, LightGBM и XGBoost.

---

### 3. Турнир библиотек градиентного бустинга

Обучены базовые версии моделей:

- XGBoost
- LightGBM
- CatBoost

Для каждой модели рассчитаны:

- MAE
- RMSE
- R²
- Overpricing Rate
- Underpricing Loss
- время обучения
- время предсказания

---

### 4. Подбор гиперпараметров

Для каждой библиотеки выполнена оптимизация параметров с помощью Optuna.

Подбирались:

#### Общие параметры

- learning_rate
- max_depth
- n_estimators

#### Специфические параметры

**XGBoost**

- gamma
- reg_alpha
- reg_lambda

**LightGBM**

- num_leaves
- min_child_samples
- reg_alpha
- reg_lambda

**CatBoost**

- l2_leaf_reg

---

### 5. Интерпретация моделей

Для лучших моделей выполнен SHAP-анализ.

Определены наиболее важные признаки:

1. engine_cc
2. make_year
3. owner_count
4. fuel_type
5. mileage_kmpl

Проведен анализ:

- бизнес-рисков;
- ошибок по брендам;
- ошибок по регионам;
- склонности модели к завышению и занижению стоимости.

---

### 6. Финальная проверка

Лучшая модель была переобучена на объединенной обучающей и валидационной выборках и протестирована на полностью отложенном тестовом наборе данных.

Полученные результаты подтвердили отсутствие признаков переобучения и хорошую способность модели к обобщению.
